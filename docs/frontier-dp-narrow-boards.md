# 窄棋盘 frontier DP：端点唯一性的精确计数与内部线索的状态爆炸（Issue #12）

研究原型，位于测试源码（`app/src/test/.../domain/FrontierPathCounter.kt`），**未接入生产**。生产唯一性 oracle 仍是 `HidatoSolver`。

## 问题设定

窄棋盘（3×N / 4×N / N×3 / N×4）上固定**端点线索**（数字 1 与 N 的位置）时的唯一性/替代路径计数：

- 只有端点线索时，一条合法完整 Hidato 解就是一条从 cell(1) 到 cell(N) 的哈密顿路径（路径本身决定数字标号）。
- 因此：唯一解 ⇔ **该端点对之间的哈密顿路径数恰为 1**；反例存在 ⇔ 计数 ≥ 2。

这是离线优化器 HARD 难度（仅 2 个线索）情形在窄棋盘上的完整子问题。

## 方法（端点情形：精确、宽度参数化）

虚拟顶点 v0 与两条**强制**边 (v0,a)、(v0,b) 把"哈密顿路径 a→b"化为"过 v0 的哈密顿环"，所有真实格子目标度数统一为 2（端点由虚拟边预置 1 度）。按列扫描；每个格子处理后，与未处理区域的界面至多 = 当前列已处理前缀 + 前一列自 r−1 起的后缀，**至多 W+1 个槽位（只依赖宽度 W）**。状态记录每个槽位的度数、连通分量标签（饱和为 0）、未处理端点计数（可选：每分量格子数）。不变量：每个分量恰有 2 个开放插头（度数缺口 + 未处理端点的虚拟插头）；标签全部饱和即提前封闭 → 剪枝（除最后一格外）；同分量两插头搭桥（成环）仅允许在最后一格。接受条件：最后一格转换前恰有一个开放分量、全部饱和、无未处理端点 —— 即单一过 v0 哈密顿环。

**复杂度**：状态数 ≤ f(W)（度数 ∈ {0,1,2} × 标签配对 × 端点 pending ∈ {0,1,2}），每状态转移 ≤ C(4,≤2)+1 = 11 种；总时间 O(N·W·f(W)·常数)、空间 O(f(W))。这不是把普通哈密顿路径树宽 DP 的结论"套用"到 Hidato——数字顺序约束在端点情形恰好被"路径即标号"吸收，因此该特殊情况有严格论证；内部线索情形见下节，**不**自动继承此结论。

## 验证（`FrontierPathCounterTest`，随全量 JVM 测试运行）

- 3×3～4×5、2×5 全部端点对（>40 组，含相邻端点、对称端点、计数为 0 的组合若出现）：DP 计数与**独立 clean-room DFS 枚举**逐一相等。
- 与生产 `HidatoSolver.countSolutions`（端点线索、大预算）三方一致：12 组 3×4～3×7 实例计数相等。
- 转置不变性：5×3 与 3×5（坐标转置）计数一致——N×3 用转置几何调用即可。
- 组件大小跟踪不改变计数（纯观测开关）。

结论：

1. **状态数对 N 严格平坦**（3×N 全部 15、4×N 全部 56），O(N·f(W)) 的宽度参数化声明在实测中成立；
2. DP 在毫秒级精确计数到 10¹⁸ 量级；生产求解器在 3×10 起**无法**完成穷举计数，3×16 起**连找一条反例都在 5000 万节点/20 秒预算内失败**（诚实返回 Unknown，绝不误报）——端点情形下 DP 严格优于 DFS 的计数与证明能力；
3. 计数可能超出 Long（3×24 已达 2.7×10¹⁸），更大棋盘需 BigInteger——当前实现未处理溢出（原型边界）。

## 内部线索的障碍（否定性结果）

固定内部线索（数字 k 在格子 cₖ）时，几何扫描顺序 ≠ 路径顺序：处理 cₖ 时其在路径上的名次未知，名次约束化为"分量两端到每个线索格的精确路径距离"。状态因此必须携带每分量、每线索的整数距离组，取值域 O(N)——**状态空间不再只依赖宽度**。

可量化的下界：任何精确内部线索扩展至少要区分**组件大小剖面**（大小决定两端点间格子数）。实测把每分量大小并入状态键后，每列状态数乘数随棋盘增长（3×N：2.5×→8×；4×N：5×→10×），且理论最坏随 N 无界（大小取值 O(N)）。加上每线索 2 个距离整数后乘数更高。因此**不建议**实现全线索 frontier DP；窄棋盘 + 多线索的唯一性仍由 `HidatoSolver`（或其等距传播优化）承担。

## 建议（go / no-go）

- **GO（已验证、保持隔离）**：端点情形的精确计数/唯一性判定，O(N·f(W))，可作为未来窄棋盘 HARD 题目（2 线索）的廉价 oracle；接入生产需另行 PR（含 BigInteger 溢出处理与 Nx3 转置封装）。
- **NO-GO**：全内部线索 frontier DP（状态携带线索距离，宽度参数化失效）。
- 本 PR 不改变生产代码路径；`HidatoSolver` 语义、预算与停止条件不变。
