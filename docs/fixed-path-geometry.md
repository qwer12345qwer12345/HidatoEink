# 固定路径几何与反例质量实验（Issue #13）

## 目的

检验固定合法路径的几何特征，是否与高价值替代路径约束有关。此实验只产生分析数据，不改变生产求解器或最少线索优化器。

## 实验设计

- 使用独立语料：3×3 小棋盘固定路径，加上当前题库全部 18 条路径；路径和题库行号固定。
- 记录每条路径的直线段长度、转弯数字位置、转弯密度，以及标签间隔 1、2、3、4、8、16 的位置 Chebyshev 距离、剩余步数 slack 和等距比例。
- 对比三类证据：合法片段反转、独立实现的有界局部路径替换原型、完整 Hidato 求解器在确定性线索探针中找到的替代路径。
- 每条反例都必须通过完整路径合法性验证；差异集合必须非空，且不能与探针给定线索冲突。
- 统计原始见证数、去重差异集合、包含关系极小约束、相对前序约束族新增的非冗余约束、差异集合重叠，以及加入各约束族前后的互不相交打包下界。
- 求解器每个探针有固定节点和时间预算；UNKNOWN 单独报告，绝不当作 UNIQUE。
- 在 3×3 案例上穷举内部线索子集，独立检查打包下界没有超过当前约束族的精确最小击中集大小。

局部替换默认窗口上限为 8，每窗口最多枚举 64 条替代路径。这个上限只会遗漏见证，不会生成未经验证的约束。重叠指标在唯一集合不超过 400 个时使用全集；更多时使用确定性等距抽样，限制成对计算成本。

## 复现

    bash tools/offline/analyze-fixed-path-geometry.sh       app/src/main/assets/unique-puzzles.tsv       tools/offline/fixed-path-geometry-corpus.tsv       /tmp/fixed-path-geometry-witnesses.csv       /tmp/fixed-path-geometry-summary.csv       /tmp/fixed-path-geometry-report.md       8 64 500000 500

输出报告和两个 CSV 会作为 GitHub Actions artifact 上传。报告包含逐实例结果、Spearman 描述性相关、约束新增数和下界变化。它们是探索性关联，不证明因果，也不能单独作为剪枝规则。下一步若有特征显示潜力，只应先用于局部窗口的搜索顺序，并在相同输入/预算下测量每秒新增非冗余约束数及求解器调用次数。

## 结果解释约定

- 合法反例：经 HamiltonianPaths.isValid 复核的完整不同路径。
- 非冗余约束：插入时没有被当前差异集合族中的某个子集包含；若新集合是已有集合的子集，它会取代被它支配的超集。
- 打包下界：是可证明的下界，不等于最优线索数；启发式贪心打包的数值可能因极小约束替换而变化。
- 相关性：语料小且棋盘尺寸不同，只用于提出下一项可证伪实验，不用于丢弃候选或宣称最优。
